Card Analyzer: Privacy Policy (Draft)

Publication status: Draft for the separate Android test branch. Not yet published as the final policy.

Card Analyzer is an on-device character card review client. You can import or paste text, JSON, Markdown, character exports, and optional images. Cards and generated model reports are kept on your device unless you choose to send them to a model provider or export them.

Information and destinations

When you choose Run Audit, the card contents, selected model, prompts and any optional portrait are sent over HTTPS to the AI provider you configure (Google Gemini, OpenAI, OpenRouter, DeepSeek or your custom HTTPS endpoint). Your API credential is sent only to the selected provider endpoint to authenticate that request. The provider independently handles data under its own terms, privacy notices, retention settings and policies. Review them before using this app.

OpenRouter model browser metadata may be requested from OpenRouter when you open it. The Android package contains no advertising SDK or analytics SDK and does not send card contents, API keys or report history to an analyzer-operated server. The app does not create an account.

On-device storage and deletion

Settings and any API keys you deliberately choose to remember are stored in local application storage. Audit results are saved locally in an IndexedDB database. Remove saved credentials by unchecking Remember API key. Clear saved reports via Audit History; clearing Android app storage or uninstalling removes all remaining local data. File exports you saved separately must be deleted by you. Model-provider data cannot be deleted by this app; consult your provider.

Permissions

Internet is used to contact your selected AI provider and retrieve a model catalog. Device document pickers let you select cards/images and export text to files you choose. The app does not request broad file storage access, device location, camera, microphone or contacts.

Safety reports and privacy inquiries

The in-app flagging form is disabled from transmission until a developer-operated receiving endpoint is configured and privacy-reviewed. No safety reports are silently submitted.
