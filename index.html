✨ What's New Release notes, by version
5.5 · Better grading, more control, fewer lost reports
  • Slop affects the final grade (10%). Now recognizes characterization collapse, contrivance, incoherence and weak human-written prose, not just stereotypical AI filler. Slop never automatically disqualifies a compelling character.
  • Example dialogue lifecycle. Optional examples teach register, not permanent characterization or canonical lore. Hypothetical scenarios are fine; essential recurring traits found only in temporary examples now earn a proportionate Inference deduction, unlike incidental actions.
  • Every greeting is considered. The main quality and slop audit always sees every selectable opening, including when individual greeting reports are sent separately. Alternate starts are never treated as simultaneous events.
  • Manual output limits. Start at 16,384 tokens for single audits or 32,768 for comparisons. Combined per-greeting grading adds 250 output tokens per greeting; separate diagnostic calls get their own smaller limit.
  • Price estimator. Preview approximate input tokens and input cost, plus a worst-case output-budget cost based on your selected limit. Uses cached OpenRouter pricing where available; actual generated output cannot be predicted.
  • Saved audit history. Reports save automatically to this browser, including partially completed reports. Reopen without another API request, pin or delete individual entries, and export a JSON history backup.
  • Structured card editor. Switch between raw imported card text and collapsible, individually editable fields. Character information, greetings and metadata retain their distinct boundaries.
  • Side-by-side comparison. Compare aligned criterion scores and slop at a glance, with separate Card A and Card B diagnostic tabs rather than one long report.
  • Remake field diff. Show which card fields were added, removed or changed and their relative sizes. The diff is informational, never an automatic reason to prefer a remake.
  • Static technical lint. Surface genuinely suspicious macro/delimiter errors before an audit. This 5.5 hotfix also prevents valid serialized Extensions JSON from being misread as broken braces.
  • Offline and accessibility polish. Reliable system-font fallback offline, clearer input warnings and more accurate disabled-button cursors.
  • Persistent design decisions. Added a documented CLAUDE.md rationale log for future modifications, so prior decisions can be challenged rather than silently forgotten.
